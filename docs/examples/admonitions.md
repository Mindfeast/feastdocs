# Admonitions

Four ready-made callouts. Each snippet is inserted exactly as shown — replace
`Text.` and go. (Three more types exist for hand-writing: `info`, `success`,
`caution` — see [Markdown features](/guide/markdown).)

## Note

```md
:::note
Text.
:::
```

:::note
Text.
:::

## Tip

```md
:::tip
Text.
:::
```

:::tip
Text.
:::

## Warning

```md
:::warning
Text.
:::
```

:::warning
Text.
:::

## Danger

```md
:::danger
Text.
:::
```

:::danger
Text.
:::

:::info Custom titles
Any admonition takes a custom title after its type: `:::warning Deprecated in v3`.
:::
