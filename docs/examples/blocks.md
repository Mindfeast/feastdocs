# Blocks

## Code block

Inserted with a `title=` attribute ready to name the file, and a language tag
to change (`ts`, `bash`, `json`, …). Highlighting happens at build time.

````md
```ts title="file.ts"
// code
```
````

```ts title="file.ts"
// code
```

## Table

A starter 2×2 — add columns with more `|` cells, rows with more lines. Tables
scroll horizontally on their own when they outgrow the page.

```md
| Column | Column |
| ------ | ------ |
| Cell   | Cell   |
```

| ------ | ------ |
| Cell   | Cell   |
