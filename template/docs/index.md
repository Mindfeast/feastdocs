# Your documentation

This is the home page. It lives at `docs/index.md` — edit it and the site
updates while `npm start` is running.

## What to do next

- Put your pages in `docs/`. Every top-level folder becomes a section in the
  navbar; every file becomes a page.
- Set your site's name and colours in `feastdocs.config.mjs`.
- Delete this page's content and write your own.

Full documentation for the framework, including every component and
configuration option, is at **[feastdocs.feast-labs.com](https://feastdocs.feast-labs.com)**.
