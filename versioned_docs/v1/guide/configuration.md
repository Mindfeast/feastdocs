# Configuration (v1)

In v1 the configuration file was smaller. This page exists to show a page whose
content differs between versions, and to give the switcher something to match
when moving between them.

```js title="feastdocs.config.mjs (v1)"
export default {
  title: 'My Docs',
  docsDir: 'docs',
};
```
